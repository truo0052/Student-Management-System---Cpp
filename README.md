# Student Management System

A comprehensive console-based student management application written in C++ that allows users to input, manage, and analyze student academic records.

## Features

- **Student Data Entry**: Input student ID, name, and three marks per student
- **Automatic Calculations**: Computes total marks and average scores automatically
- **Pass/Fail Status**: Determines passing status based on 50% threshold
- **Top Performer Identification**: Identifies and displays the highest-scoring student
- **File Persistence**: Save and load student records to/from text files
- **Memory Management**: Proper dynamic memory allocation and deallocation

## Technical Details

- **Language**: C++ (C++20 standard)
- **Build System**: CMake
- **File I/O**: Text-based file storage for student records
